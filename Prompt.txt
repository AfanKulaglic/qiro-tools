Build a complete premium SaaS web application called "LinkQR Tools" using Vite, React, TypeScript, Tailwind CSS, Firebase Firestore, Firebase Hosting, React Router DOM, Framer Motion, lucide-react icons, and a modern client-side QR code library.

This must not look like a basic free online tool.
It must look like a serious, high-end SaaS company website worth millions of dollars.

The product is an all-in-one platform for:
1. URL shortening with our own domain/subdomain
2. QR code generation
3. Image conversion
4. Link history
5. Basic click tracking
6. Future-ready dashboard structure
7. Professional marketing pages

The design should be inspired by premium SaaS websites and modern link-management platforms such as Bitly, Rebrandly, Canva-style tool pages, Adobe Express-style utility pages, modern Webflow SaaS landing pages, and premium AI tool websites.

====================================================
CUSTOM DOMAIN URL SHORTENER
====================================================

Support two short link formats:

Main domain format:
https://mydomain.com/s/abc123

Short subdomain format:
https://go.mydomain.com/abc123

Use environment variable:

VITE_SHORT_DOMAIN=https://go.mydomain.com

If VITE_SHORT_DOMAIN exists:
Generated short links should be:
VITE_SHORT_DOMAIN + "/" + slug

If VITE_SHORT_DOMAIN does not exist:
Generated short links should be:
window.location.origin + "/s/" + slug

Routes:
- /s/:slug should redirect on the main domain
- /:slug should redirect on the short subdomain
- normal routes must be protected from being treated as slugs

- "Redirecting..."

Behavior:
1. Read slug
2. Check Firestore
3. If exists and active:
   - increment clicks
   - update lastClickedAt
   - redirect using window.location.replace(longUrl)
4. If not found:
   show polished not found state
5. If inactive:
   show inactive link state
6. If error:
   show error state

Use Firestore increment().
